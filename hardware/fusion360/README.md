# Fusion 360 Files

Native Fusion 360 project files for the Open Winder assembly go here (.f3d exports, or a note pointing to the hosted Fusion 360 project if you'd rather link than commit binary CAD files directly).

Current assembly includes:
- Winder body/frame
- Load cell pulley (three-wheel over/under/over routing, 30° strand angle, 1:1 force ratio)
- Laser module mount (Ø9 x 33 mm housing, emitting face at world origin, beam along +Z)

See ../step/ for exported STEP files if you want a CAD-tool-agnostic format alongside the native files.
