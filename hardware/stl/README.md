# Open Winder STL Files

Print-ready STLs for the Open Winder body, clamps, motor brackets, limit-switch housings and tension-sensor housing.

All parts are printed in **PETG**.

| File | Part |
|---|---|
| Housing_1.stl | Main housing |
| Top_Clamp_1.stl / Bottom_Clamp_1.stl | Clamps |
| Motor_Bracket_Front_Top_Spindle_1.stl / Motor_Bracket_Rear_Top_Spindle_1.stl | Spindle (winder) motor brackets |
| Motor_Bracket_Front_Top_Traverse_1.stl / Motor_Bracket_Rear_Top_Traverse_1.stl | Traverse motor brackets |
| Top_Limit_Housing_1.stl / Bottom_Limit_Housing_1.stl | Limit-switch housings |
| Tension_Sensor_Housing_1.stl | Load-cell (tension sensor) housing |

Editable CAD is in `../step/` (STEP) and `../fusion360/` (Fusion 360).
